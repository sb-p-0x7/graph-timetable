# 시간표 그래프 (timetable-graph)

> 겹치는 수업은 간선으로 잇고, 시간표는 독립집합으로 고른다

수업(과목·분반)을 **노드**, 동시에 들을 수 없는 두 수업을 **간선**으로 연결한 **충돌 그래프**를 그려 주는 시간표 빌더.
노드를 클릭해 수업을 고르면 간선으로 이어진 이웃 노드는 회색으로 잠겨 선택할 수 없고, 고른 수업은 옆의 주간 시간표에 바로 채워진다.
즉, 그래프의 **독립집합(independent set)** 을 눈으로 보면서 고르는 도구다.

## 실행 방법

설치할 것이 없다. `index.html` 을 브라우저(Chrome, Safari, Firefox, Edge)에서 열면 끝.

```bash
open index.html
```

로컬 서버로 띄우고 싶다면:

```bash
python3 -m http.server 8765
```

그다음 <http://localhost:8765/> 로 접속한다.

## 화면 구성

```
┌ 과목 목록 ┬───────── 충돌 그래프 ─────────┬ 주간 시간표 ┐
│ 색 점·이름 │  ○ 노드 = 과목(분반)          │ 월 화 수 목 금 │
│ 교수·학점  │  ─ 실선 = 시간 겹침            │ 선택한 수업이 │
│ 편집·삭제  │  ┄ 점선 = 같은 과목·다른 분반  │ 색 블록으로  │
│ 선택 N과목 │  회색 = 선택 불가              │ 채워짐       │
└──────────┴────────────────────────────────┴────────────┘
```

## 사용법

### 그래프에서 고르기

| 동작 | 결과 |
|---|---|
| 노드 **클릭** | 선택 / 선택 해제 |
| 잠긴(회색) 노드 클릭 | 아무 일도 없음. 흔들리며 마우스를 올리면 **왜 안 되는지** 툴팁으로 알려 줌 |
| 노드 **드래그** | 놓은 자리에 고정 (선택은 바뀌지 않음). 파일 불러오기·샘플로 초기화 때 고정이 풀린다 |
| 노드에 **마우스 올리기** | 이웃 노드·간선 강조, 시간표에 그 수업 자리를 점선으로 미리 보기 |
| 간선에 마우스 올리기 | 두 수업이 왜 충돌하는지 표시 |
| 「선택 해제」 | 선택 전부 해제 |

원 안의 숫자는 **분반**, 아래 글자는 **과목명**이다. 같은 과목의 분반은 같은 색을 쓴다.

키보드로는 왼쪽 과목 목록을 쓴다. `Tab` 으로 항목을 옮겨 다니고 `Enter`/`Space` 로 선택·해제한다.

### 충돌 규칙

두 수업 A, B 사이에 간선이 생기는 경우:

1. **시간 겹침** — 같은 요일에 `A.start < B.end && B.start < A.end`. 10:00–11:00 과 11:00–12:00 처럼 딱 붙은 수업은 겹치지 않는다.
2. **같은 과목·다른 분반** — 과목명이 같으면 시간이 달라도 하나만 고를 수 있다.

선택 집합은 항상 독립집합이다. 과목을 편집해서 이미 고른 수업과 충돌하게 되면 **편집한 과목**의 선택이 풀리고 알림이 뜬다.

### 관심 학과로 과목 추리기

학교 전체 강의처럼 과목이 많을 때 쓰는 기능이다. 과목이 80개를 넘거나 데이터에 개설학과·교과목번호가 있으면 왼쪽 위에 **관심 학과** 칩과 **전체 과목 검색**이 나타난다.

- 학과 칩을 누르면 그 학과의 과목이 그래프에 올라온다. 여러 학과를 함께 고를 수 있다.
- 검색창에 과목명, 교과목번호(예: `EC2208`), 교수 이름을 적으면 전체 목록에서 찾는다. 「＋ 추가」 를 누르면 학과와 상관없이 그 과목을 그래프에 올린다. 이미 고른 수업과 겹치는 과목은 「선택한 수업과 충돌」 로 표시된다.
- 검색 결과에 마우스를 올리면 그래프에 없는 과목이라도 시간표에 자리가 미리 보인다.
- 선택한 수업은 학과 칩을 꺼도 그래프에 남는다.
- 개설학과 열이 없으면 교과목번호의 영문 접두어(`EC2208` → `EC`)로 학과를 묶는다.
- 교과목번호가 있으면 같은 번호끼리 "같은 과목"으로 보고 분반 간선을 잇는다. 번호가 없으면 과목명으로 판단한다.

관심 학과와 직접 추가한 과목도 자동 저장되고, JSON 내보내기에 함께 들어간다.

### 주간 시간표

- 기본 월~금 09:00–18:00. 데이터에 토·일이나 이른/늦은 시간이 있으면 자동으로 넓어진다.
- 그래프 노드에 마우스를 올리면 그 수업의 자리가 점선으로 미리 보인다. 잠긴 수업이면 빗금으로 표시되고, 부딪히는 선택 블록에 빨간 테두리가 생긴다.
- 블록을 클릭하면 선택이 해제된다.

### 과목 추가·편집·삭제

「＋ 과목 추가」 를 누르면 폼이 열린다. 과목명은 필수, 나머지(분반·학점·교수·강의실)는 선택. 수업 시간은 여러 개 넣을 수 있고, 비워 두면 **시간 미정** 과목(사이버 강의 등)으로 저장된다.
목록의 항목에 마우스를 올리면 「편집」「삭제」 버튼이 나타난다.

입력·선택 상태는 브라우저의 localStorage 에 자동 저장되어 새로고침해도 유지된다. 「샘플로 초기화」 로 내장 샘플 데이터(컴공 전공 14과목)로 되돌릴 수 있다.

### 파일 불러오기 / 내보내기

「파일 불러오기」 버튼 또는 창 어디에나 **드래그 앤 드롭**. JSON 과 CSV 를 자동 판별한다.
불러오면 기존 과목을 **대체**한다. 확인 창에 읽은 과목 수와 오류로 건너뛴 행 수가 먼저 나오고, 불러온 뒤에도 알림의 「되돌리기」로 이전 상태를 되살릴 수 있다. 잘못된 행은 행 번호와 함께 알림의 「자세히」에 정리된다.

「JSON 내보내기」 는 과목 목록과 현재 선택을 `timetable-YYYYMMDD.json` 으로 저장한다. 다시 불러오면 선택까지 복원된다.

`samples/` 폴더에 내장 샘플과 같은 내용의 `sample.json`, `sample.csv` 가 있다.

## 데이터 형식

### JSON

```json
{
  "format": "timetable-graph",
  "version": 1,
  "courses": [
    {
      "id": "c-s01",
      "name": "자료구조",
      "section": "01",
      "professor": "김민수",
      "credits": 3,
      "room": "공학관 301",
      "slots": [
        { "day": "월", "start": "09:00", "end": "10:15" },
        { "day": "수", "start": "09:00", "end": "10:15" }
      ]
    }
  ],
  "selected": ["c-s01"]
}
```

- `courses` 배열만 있어도 되고, `id`·`slots`·`selected` 가 없어도 된다(`id` 는 자동 생성).
- 선택 항목: `code`(교과목번호), `dept`(개설학과), `kind`(이수구분). 문서 끝의 `interests: { depts: [...], pinned: [...] }` 는 관심 학과와 직접 추가한 과목이다.
- `day` 는 `월`/`월요일`/`1`/`mon` 모두 허용 (1 = 월 … 7 = 일). 시간은 `HH:MM` 24시간제.

### CSV

첫 줄은 헤더. 열 순서는 자유이고 한글·영문 이름을 모두 알아본다. **수업 시간 하나당 한 줄**을 쓰고, 같은 과목·분반의 행은 하나로 합쳐진다.

```csv
과목명,분반,교수,학점,강의실,요일,시작,종료
자료구조,01,김민수,3,공학관 301,월,09:00,10:15
자료구조,01,김민수,3,공학관 301,수,09:00,10:15
사이버윤리,01,,1,,,,
```

| 항목 | 인식하는 헤더 |
|---|---|
| 과목명 (필수) | `name` `과목` `과목명` `교과목명` `course` `title` |
| 교과목번호 | `code` `교과목번호` `과목번호` `과목코드` `학수번호` |
| 개설학과 | `dept` `department` `개설학과` `학과` `학부` `전공` |
| 이수구분 | `kind` `category` `이수구분` `구분` |
| 분반 | `section` `분반` `sec` (비우면 `01`) |
| 교수 | `professor` `교수` `교수명` `prof` |
| 학점 | `credits` `credit` `학점` |
| 강의실 | `room` `강의실` `장소` |
| 요일 | `day` `요일` |
| 시작 / 종료 | `start` `시작` / `end` `종료` |

- 요일·시작·종료를 모두 비우면 시간 미정 과목이 된다.
- 큰따옴표는 칸 맨 앞에 올 때만 인용으로 본다. `김"철수` 처럼 칸 중간에 있는 따옴표는 그대로 글자로 읽는다.
- 엑셀이 저장한 파일도 그대로 읽는다: BOM, CRLF, `9:00:00` 같은 초 단위 시간, 분반 `01`→`1` 변환, **CP949(EUC-KR) 인코딩** 자동 감지.

## 자체 테스트

```
index.html#selftest
```

주소 끝에 `#selftest` 를 붙여 열면 앱 대신 테스트 결과 표가 나온다. 시간 파싱, 겹침 판정, 그래프 생성, 선택 규칙, CSV/JSON 파싱, 힘 기반 배치의 안정성을 검사한다.
평소 앱 화면에서는 브라우저 콘솔로 `window.TT` (순수 로직)와 `window.app.store.getState()` (현재 상태)를 직접 다룰 수 있다. 자체 테스트 화면에는 `window.TT` 만 있다.

## 폴더 구조

```
timetable-graph/
├── index.html           # 앱 전체 (CSS + 순수 로직 TT + 자체 테스트 + UI)
├── README.md
├── samples/
│   ├── sample.json      # 내장 샘플과 동일 (JSON 형식 예시)
│   └── sample.csv       # 같은 데이터의 CSV 예시
└── .claude/launch.json  # python http.server 미리보기 설정
```

`index.html` 안은 세 개의 `<script>` 로 나뉜다.

| 블록 | 역할 |
|---|---|
| `tt-core` | DOM 을 건드리지 않는 순수 함수. 정규화, 충돌 판정, 그래프, 선택 규칙, CSV/JSON, 힘 기반 배치(`TT.Force`) |
| `tt-tests` | `TT.runSelfTests()` |
| `tt-app` | Store, 그래프 뷰(SVG), 시간표 그리드, 과목 목록, 입력 폼, 불러오기/내보내기 |

## 제한사항

- 자정을 넘기는 수업(예: 22:00–01:00)은 입력할 수 없다.
- 색은 12가지를 돌려쓰므로 과목명이 13개를 넘으면 색이 겹칠 수 있다.
- 불러오기는 기존 데이터를 대체한다. 합치기(append)는 지원하지 않는다.
- `samples/sample.json` 은 내장 샘플에서 생성한 파일이므로, 내장 샘플을 바꾸면 함께 갱신해야 한다.
